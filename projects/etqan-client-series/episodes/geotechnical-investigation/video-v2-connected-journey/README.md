# إتقان | من الفحص إلى القرار — تطوير الحلقة الجيوتقنية

## من استكشاف التربة… إلى قرار التأسيس

نسخة مستقلة مطوّرة بعد ملاحظات المستخدم: الموقع أرض خالية قبل البناء، الحفارة نفسها التي أعجبته، ونفس نظام الفيديو الرأسي والكحلي/الذهبي والهيدر والفوتر وشعار MS.

فيديو60 ثانية، 1080×1920، 30fps، H.264 مع AAC stereo48kHz. يبدأ الحفر من أول إطار، ويستمر أثناء تغير العنوان دون إعادة الحركة. تُتبع العينة من طرف الأداة إلى الحفظ ثم المختبر. توسّع المختبر إلى ثلاثة أمثلة من ملف اختبارات المستخدم بدل اختزاله في المناخل.

| الوقت | المشهد |
|---|---|
| 0–16 | حفر وسحب العينة من أرض خالية |
| 16–21 | انتقال متصل للعينة وحفظها |
| 21–29 | التدرّج الحبيبي وتصنيف التربة |
| 29–37 | حدود أتربرج: حد السيولة مثالًا |
| 37–45 | القص المباشر: تحميل رأسي ثم إزاحة أفقية |
| 45–54 | ربط بيانات الموقع والمختبر بالتحليل والتقرير والتوصيات |
| 54–60 | الهوية والتواصل |

## الملفات

- `renders/etqan-series-geotechnical-v2-60s.mp4`: الفيلم الكامل، موسيقى ومؤثرات فقط.
- `renders/etqan-series-geotechnical-v2-cover.png`: غلاف من إطار الفيلم الفعلي عند الثانية1.
- `renders/etqan-series-geotechnical-v2-source.zip`: المصدر والأصول ودليل إعادة الإنتاج وأدلة الفحص.
- `narration/script.txt` و`cues.json`: نص اختياري ونوافذ تسجيل مقترحة؛ لم تُولد أو تُدمج أصوات بشرية، وفق طلب المستخدم أن يضيف التعليق لاحقًا.
- `public/score.m4a`: الموسيقى والمؤثرات الأصلية منفصلة.

## التحرير وإعادة الإنتاج

Node24، Python3، Chromium، FFmpeg. إصدارات JavaScript مثبتة بملف القفل. سكربتات المتصفح تستخدم `/usr/bin/chromium`؛ يمكن تعديل المسار بحسب النظام.

```sh
npm ci
python3 -m pip install -r requirements.txt
python3 scripts/make_audio.py
npm run check
npm run studio
```

التركيب الكامل `EtqanSeriesGeotechnicalV2`، ولكل مرحلة تركيب مستقل. مشروع الإصدار السابق لا يلزم لتشغيل هذا المصدر.

```sh
mkdir -p /tmp/etqan-geo-v2
TMPDIR=/tmp/etqan-geo-v2 npm run render
node scripts/check-geometry.mjs
python3 scripts/verify.py
python3 scripts/export_review.py
python3 scripts/check_creator.py
TMPDIR=/tmp/etqan-geo-v2 node scripts/check-playback.mjs
python3 scripts/package_source.py
```

التصدير يستأنف أجزاء متطابقة مع بصمة المصدر. `work/` و`node_modules/` ملفات مؤقتة غير مشمولة بأرشيف المصدر. التصدير إلى MP4 يحوّل الألوان إلى BT.709 محدود المدى، مع faststart.

## حدود التمثيل

رسوم هندسية مظللة ومتحركة بعناصر SVG مرتبطة بالإطارات؛ ليست تصويرًا حقيقيًا أو إعادة تصميم فوتورياليستي أو نموذجCAD معتمدًا. الأبعاد والأزمنة مختصرة لأغراض الإعلان؛ لا يُعرض عمق جسة أو عدد ضربات أو نتائج أو شهادات أو قراءات مختلقة. كأس كازاغراندي مثال لحد السيولة داخل موضوع حدود أتربرج. صندوق القص مقطع توضيحي؛ لا يمثل كامل تجهيز العينات والتحكم والتصريف ومدة الاختبار.

المراجع ودقة اختيار أمثلة المعمل في `notes/`. لا مبانٍ قائمة في موقع الجسات، ولا توسع إلى اختبارات/خدمات المرجع الأوسع دون تحديدها. التقرير غلاف توضيحي بلا نتائج أو مشروع أو عميل أو توقيع مختلق.

الهيدر والفوتر وشعار MS والخط وألوان الحفارة محفوظة من النسخة السابقة؛ يثبت `geometry-check.json` تطابق ملفات الرسم والهوية مع بصماتها المثبتة. جميع الفيديوهات والمشروعات السابقة محفوظة.
