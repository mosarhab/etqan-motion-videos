# إتقان | من الفحص إلى القرار — الحلقة الأولى

**وقت الصب… ماذا نتحقّق منه؟**

فيديو رأسي مستقل، 1080×1920، 30 إطارًا/ثانية، 60 ثانية. يربط اختبار الهبوط وقياس حرارة الخرسانة بقيمة الفحص للعميل، ثم يجمع المؤشرين في لقطة تفسّر دورهما ضمن متطلبات المشروع. النسخة الحالية موسيقى ومؤثرات أصلية فقط؛ لم يُولد تعليق جديد ولم يُعد استخدام تسجيل الإعلان العام. نص الحلقة جاهز للتسجيل بشكل منفصل.

## المشاهد

- 0–6: سؤال الحلقة وهوية السلسلة المعتمدة.
- 6–24: قوام الخرسانة وقابلية التشغيل، مع رفع القالب رأسيًا مرة واحدة ثم وضعه إلى الجانب.
- 24–40: قياس الحرارة، مع إدخال المسبار في قطاع توضيحي للخرسانة، دون قراءة مختلقة.
- 40–52: قراءة المؤشرين مع متطلبات المشروع؛ تقييم المقاومة له اختبار آخر.
- 52–60: هوية السلسلة والتواصل، مع الأيقونة على يسار الرقم.

الهيدر والفوتر وشعار ETQAN الأصلي وشعار MS الأصلي ثابتة. رقم الفوتر 0535588975، والبريد info@etqanelbnaa.com، والعنوان حي القادسية، الرياض. رقم الختام 0551603205. كل الإعلانات السابقة محفوظة دون تعديل.

## التسليم

- renders/etqan-series-01-pouring-60s.mp4: الحلقة بالموسيقى والمؤثرات.
- renders/etqan-series-01-pouring-cover.png: غلاف مأخوذ من الختام الفعلي.
- renders/etqan-series-01-pouring-source.zip: المصدر والخط والشعارات والصوت وتقارير المراجعة.
- narration/script.txt: نص التعليق المقترح، جاهز للنسخ إلى خدمة التسجيل.
- narration/cues.json وrecording-guide.srt: توقيتات استرشادية، وليست محاذاة لتسجيل مولّد.

## التعديل وإعادة البناء

Node.js، Chromium في /usr/bin/chromium، FFmpeg/FFprobe وPython مطلوبة.

```sh
npm ci
python3 -m pip install -r requirements.txt
npm run studio
npm run check
python3 scripts/make_audio.py
npm run render
node scripts/check_equipment.mjs
python3 scripts/verify.py
python3 scripts/check_creator.py
python3 scripts/export_review.py
node scripts/check-playback.mjs
python3 scripts/package_source.py
```

كل مشهد مسجل مستقلًا داخل Studio. Main timeline يستخدم TransitionSeries وتداخل 18 إطارًا. src/Equipment.tsx يحدد هندسة المخروط والمسبار وحركتهما. src/Brand.tsx هو إطار الهوية المعتمد.

## حدود العرض

مخططات SVG هندسية متحركة ومظلّلة، وليست تصويرًا فوتورياليستيًا أو محاكاة سوائل معتمدة أو إجراء اختبار كاملًا. حركة الهبوط تحفظ حجمًا تقريبيًا لمجسم جذع مخروط؛ القيم البكسلية ليست نتائج اختبار. شاشة المسبار بلا أرقام مختلقة. تقييم النتائج مرتبط بمتطلبات المشروع، ولا تُعرض قيمة قبول عامة.

لم يُسجل تعليق الحلقة بعد. فحص الصوت تقني عبر فك الترميز والمستويات والمطابقة، وليس اعتمادًا بشريًا لجودة أداء صوتي غير موجود.
