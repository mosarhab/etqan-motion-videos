# إتقان | من الفحص إلى القرار — V6

نسخة مستقلة100 ثانية، رأسية1080×1920 و30fps وH.264/AAC، تنفذ تكوينSPT الذي وافق عليه المستخدم بعد مشاهدة الصورة التصورية. الهيدر والفوتر وشعارMS والشعار الرسمي والخط ومدة المشاهد محفوظة.

التعديل الرئيسي: تفصيلة كبيرة على يسار الكادر، بسارية جزئية وإطار توجيه مثبت وحوامل وبراغٍ وقضيب طرق متصل بالمطرقة والسندان وأداة أخذ العينة، وقطاع تربة أقل سيطرة. حركة الطرق والاختراق والاستخراج وتجميع العينة مؤلفة بالعناصر وفق الإطارات، مع اقتراب بسيط يعود قبل نقل العينة للحفظ. عنوان الاختبار على يمين التفصيلة دون تقاطع معها.

النص الكيميائي أصبح «تقييم التأثير الكيميائي للتربة»، و«لدعم توصيات حماية الأساسات والخرسانة الملامسة للتربة». فحوص الكيمياء هنا على التربة والصخور، لا مشهد اختبار خرسانة.

## الملفات

- `renders/etqan-series-geotechnical-v6-100s.mp4`: الفيلم الكامل بموسيقى ومؤثرات أصلية فقط.

- `renders/etqan-series-geotechnical-v6-source.zip`: المصدر والأصول والخط والتراخيص وأدلة الفحص.

## إعادة الإنتاج

Node24،Python3،FFmpeg،Chromium. المتصفح `/usr/bin/chromium` قابل للتعديل بحسب البيئة. إصداراتJavaScript مثبتة بملف القفل.

```sh
npm ci
python3 -m pip install -r requirements.txt
npm run check
npm run studio
```

تركيبStudio الرئيسي `EtqanSeriesGeotechnicalV6` على المنفذ3032. لكل مشهد تركيب مستقل. ملف الصوت الأصلي مرفق، وإعادة توليده اختيارية بواسطة `scripts/make_audio.py`.

```sh
mkdir -p /tmp/etqan-v6
TMPDIR=/tmp/etqan-v6 npm run render
node scripts/check-geometry.mjs
python3 scripts/verify.py
python3 scripts/export_review.py
python3 scripts/check_spt_visibility.py
python3 scripts/check_creator.py
TMPDIR=/tmp/etqan-v6 node scripts/check-playback.mjs
python3 scripts/package_source.py
```

تُعاد جميع الإطارات من المصدر عند غياب ذاكرة التصدير. في هذه النسخة احتُفظ بالأجزاء الصامتة التي لا تتقاطع مع المشهدين المعدلين بعد فحص تطابق المصدر والأصول والتوقيتات؛ رسمت كل الأجزاء المتأثرة وأعيد ترميز الفيلم وفحصه كاملًا. الدليل في `revision-cache-check.json`. سكربت إعادة الاستخدام اختياري ولا يحتاجه المصدر المستقل.

## حدود التنفيذ

التكوين مستلهم من الصورة المعتمدة؛ التنفيذ رسومSVG هندسية مظللة ومتحركة، بخامات وتفاصيل تختلف عن الملمس الفوتوريالي للصورة التصورية. الصورة لم تستخدم كخلفية أو مشهد ساكن، وليست داخل أصول الفيديو. لا تصوير ميداني أو نماذجCAD أو محاكاة معتمدة، والأبعاد والأزمنة مختصرة للشرح.

لا نتائج أو قيمN أو أعماق أو منسوب مياه أو بيانات مشروع مختلقة. مراجعة التقرير للمحتوى لا تعتمد حساباته أو تثبت امتثال المختبر لمواصفة. التقرير الخاص والتسجيلات القديمة وExcel خارج التسليم العام. جميع النسخ السابقة محفوظة.
