# إتقان البناء — النسخة الرأسية الرابعة

تعديل مستقل لآخر نسخة رأسية، بدقة 1080×1920 ونسبة 9:16، ومدته 60 ثانية بمعدل 30 إطارًا/ثانية. جميع النسخ السابقة محفوظة دون تعديل.

## الإضافات المعتمدة

- عدّاد دائري ذهبي فوق حوض المعالجة، بعنوان «عُمر العينة».
- يوضح مرور عمر العينة بالأيام، محسوبًا من الصب، وليس مدة بقائها في حوض الماء.
- يبدأ تقدّم العمر بعد اكتمال إنزال الرف والغمر، ويصل إلى ٢٨ يومًا عند الثانية 41 من الفيلم، ثم يثبت قبل الانتقال إلى الضغط.
- أُزيل النص التوضيحي الصغير تحت العدّاد بطلب المستخدم. يبقى عنوان «عُمر العينة» وصيغ الأيام؛ العمر مثال شائع، وليس قاعدة لكل العينات.
- أُضيف الرقم `0551603205` بجوار «تواصل معنا» في اللقطة الأخيرة، دون تغيير رقم الفوتر الثابت.
- نص مشهد المعالجة: «معالجة العينات وفق متطلبات المواصفات القياسية».
- نص الخاتمة: «أجهزة مُعايرة… واختبارات وفق المواصفات القياسية».

العبارات الخدمية مضافة بناءً على طلب المستخدم وتأكيده لأسلوب العمل. لم تُضف أرقام مواصفات، أو شهادات، أو علامات اعتماد، أو نتائج اختبار غير مقدمة. لا يتغير ترتيب الفحص: الهبوط والحرارة، إعداد عينات المقاومة الأسطوانية، المعالجة، ثم الضغط.

## الملفات

- `renders/etqan-concrete-client-portrait-v4-60s.mp4`: الفيديو الرأسي الكامل بالموسيقى والمؤثرات دون تعليق صوتي.
- `renders/etqan-concrete-portrait-v4-cover.png`: إطار كامل من الفيديو يظهر عدّاد عمر العينة.
- `renders/etqan-concrete-portrait-v4-source.zip`: المصدر والخط والشعار والصوت ودليل التسجيل ومذكرة فكرة السلسلة وتقارير الفحص.
- `notes/SERIES-CONCEPT.md`: فكرة السلسلة المحفوظة سابقًا؛ لا تُطلق تسمية السلسلة في هذا الفيديو.
- `narration/script.txt` و`cues.json`: نص تسجيل مقترح، وليس ملف تعليق مولّدًا أو محاذاة لتسجيل فعلي.

الهيدر والفوتر والافتتاحية «القوة لا تُفترض… بل تُختبر» والجمل المعدّلة من النسخة الثانية باقية. رقم الفوتر الثابت `0535588975`، ورقم التواصل الإضافي في الخاتمة فقط `0551603205`، والبريد `info@etqanelbnaa.com`، والعنوان «حي القادسية، الرياض». الشعار الأصلي مطابق لجذر المستودع، مع المعالجة البيضاء والذهبية المطلوبة سابقًا ودون تغيير نسب التصميم.

## التعديل والبناء

- `src/SampleAge.tsx`: رسم العدّاد ومكانه وعباراته وصيغ الأيام.
- `src/age-timing.ts`: التوقيت والتقدّم من يوم واحد إلى ٢٨ يومًا. الزمن هنا محلي داخل مشهد المعالجة الذي يبدأ عند الثانية 32 من الفيلم.
- `src/Curing.tsx`: حوض الماء، غمر الأسطوانات، ونص المواصفات.
- `src/Closing.tsx`: عبارة المعايرة والمواصفات ورقم التواصل بجوار الدعوة في الخاتمة.
- `src/Scene.tsx` و`Brand.tsx`: التوزيع الرأسي والانتقالات والهيدر والفوتر.
- `src/Root.tsx`: تركيب الستين ثانية ومشاهد Studio المستقلة.

متطلبات البناء: Node.js، وChromium في `/usr/bin/chromium`، وFFmpeg/FFprobe، وPython. من مجلد المشروع:

```sh
npm ci
python3 -m pip install -r requirements.txt
npm run studio
npm run check
npm run review
npm run render
node scripts/check_age.mjs
python3 scripts/check_geometry.py
python3 scripts/verify.py
python3 scripts/export_review.py
node scripts/check-playback.mjs
python3 scripts/package_source.py
```

شغّل Studio في نافذة منفصلة. مصدر الصوت الجاهز في `public/score.m4a` هو نفس الموسيقى والمؤثرات الأصلية للنسخة السابقة؛ إعادة توليفه اختيارية. لا تُشحن التبعيات أو التخزين المؤقت. رابط Studio المحلي للمعاينة وليس رابط التسليم.

## حدود العرض

الرسوم الهندسية SVG متحركة، وليست مشاهد مخبرية ثلاثية الأبعاد أو صورًا ثابتة أو تصويرًا حقيقيًا. تُختصر مراحل الملء والدمك والانتظار وتجهيز الأسطح؛ الفيلم تعريفي دعائي وليس إجراء مواصفة كاملًا أو محاكاة معايرة للسوائل والكسر.

العدّاد توضيح مُسرَّع لعمر العينة، وليس سجلًا لعينة فعلية أو نتيجة اختبار. لا يعني عرض ٢٨ يومًا أن كل الاختبارات تجرى في العمر نفسه، ولا أن المعالجة في الماء تبدأ لحظة الصب. يعرض الحوض عينات متصلبة مفكوكة القوالب.

لم يُولد تعليق رجالي جديد؛ بقيت الموسيقى والمؤثرات الأصلية مع دليل تسجيل مقترح. مراجعة الصوت تقنية عبر المستويات وفك الترميز والمطابقة مع الأصل، وليست جلسة استماع بشرية أو اعتماد استوديو صوت. العبارة الإنجليزية داخل الشعار جزء من الأصل؛ النصوص المؤلفة للفيلم عربية، باستثناء بيانات التواصل التي اعتمدها المستخدم.
