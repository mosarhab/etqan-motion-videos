# إتقان | من الفحص إلى القرار — V5

حلقة رأسية100 ثانية،1080×1920،30fps،H.264/AAC. نسخة مستقلة تصحح مشهدSPT وتراجع محتوى الفيلم مقابل التقرير الذي أرسله المستخدم. الشكل العام والحفارة الأصلية والافتتاحية والهيدر والفوتر وMS والخط وألوان الهوية محفوظة.

## التعديلات

- تفصيلة متحركة للاختراق القياسي بدل إعادة عرض الحفارة كاملة: مطرقة، سندان، عمود متصل وأداة عينة عند قاع الجسة، ثم استخراج وحفظ العينة. عولج خلل SVG الذي كان يخفي العمود الرأسي ذي التدرج اللوني.
- ضغط عينة صخرية بدل القص المباشر، وتحضير المستخلص والفحوص الكيميائية بدل جهاز البيزومتر؛ البديلان موثقان في التقرير، والاختباران المحذوفان لم يوثق تنفيذهما فيه.
- أنواع الصخور أمثلة عامة، وحدود أتربرج مرتبطة بنوع العينة. ملاحظات المياه تدخل في التحليل دون ادعاء منسوب دائم.
- لا نتائج أو أعماق أو قيمN أو بيانات مشروع مختلقة. راجع `notes/report-content-review.md` لتفاصيل المراجعة وصفحات التقرير.

| الوقت | المحتوى |
|---|---|
| 0–12 | أرض الموقع، كشف الطبقات، الجسات |
| 12–22 | أمثلة عامة لأنواع الصخور وتوصيف الحالة |
| 22–43 | SPT ثم استخراج العينة وحفظها |
| 43–51 | المحتوى المائي |
| 51–60 | التدرّج الحبيبي وتصنيف التربة |
| 60–69 | حدود أتربرج |
| 69–78 | مقاومة ضغط عينات الصخور |
| 78–86 | الفحوص الكيميائية |
| 86–94 | التحليل والتقرير وتوصيات التأسيس |
| 94–100 | الهوية والتواصل |

## المخرجات

- `renders/etqan-series-geotechnical-v5-100s.mp4`: الفيلم الكامل بالموسيقى والمؤثرات الأصلية فقط.
- `renders/etqan-series-geotechnical-v5-cover.png`: غلاف فعلي من MP4 عند4.5ث.
- `renders/etqan-series-geotechnical-v5-source.zip`: المصدر والأصول والخط والتراخيص وأدلة الفحص.
- `public/score.m4a`: الموسيقى والمؤثرات منفصلة. لا صوت بشري مولد أو تسجيل مدمج. ملف الفويس الجديد الذي وصفه المستخدم بأنه90 ثانية لم يرفع بعد؛ النص في `narration/` مرجع أداء لا محاذاة معتمدة.

## التحرير والتصدير

Node24، Python3، FFmpeg، Chromium. المتصفح في السكربتات `/usr/bin/chromium` قابل للتعديل. إصدارات JavaScript مثبتة بملف القفل.

```sh
npm ci
python3 -m pip install -r requirements.txt
python3 scripts/make_audio.py
npm run check
npm run studio
```

تركيب Studio الرئيسي `EtqanSeriesGeotechnicalV5`، المنفذ3031، مع تراكيب مستقلة للمشاهد قابلة للتحرير.

```sh
mkdir -p /tmp/etqan-v5
TMPDIR=/tmp/etqan-v5 npm run render
node scripts/check-geometry.mjs
python3 scripts/verify.py
python3 scripts/export_review.py
python3 scripts/check_spt_visibility.py
python3 scripts/check_creator.py
TMPDIR=/tmp/etqan-v5 node scripts/check-playback.mjs
python3 scripts/package_source.py
```

أعيد رسم كل إطارات النسخة الجديدة؛ لا استعارة لأجزاء تصدير V4 في هذا الإصدار. استؤنفت الأجزاء غير المتأثرة من V5 بعد تصحيح تلامس لوح الضغط؛ بصمات المصدر ونطاق المشهد والأجزاء المعاد رسمها موثقة في `revision-cache-check.json`، ثم أعيد ترميز الفيلم وفحصه كاملًا. التصدير من المصدر المستقل يعيد رسم الجميع عند غياب الذاكرة المحلية. الأرشيف لا يتضمن ذاكرة التصدير أو التبعيات أو التقرير الخاص أو تسجيلات المستخدم السابقة أو Excel.

## حدود التمثيل

رسوم هندسية SVG مظللة ومتحركة، ليست تصويرًا ميدانيًا أو نماذج3D فوتوريالية أو محاكاة اختبار معتمدة. الأبعاد والأزمنة مختصرة. الحفارة مستلهمة من مرجع المستخدم وليست إعادة بناء لحفارة مشروع التقرير. مراجعة المحتوى لا تعتمد حسابات التقرير أو تثبت مطابقة المختبر لمواصفة. كل الإصدارات السابقة محفوظة دون تعديل.
