# إضافات النسخة الثالثة

طلب المستخدم إضافة عداد وقت إلى مشهد معالجة العينات، ثم توضيح الالتزام بمعايرة الأجهزة والمواصفات. نوقش ووافق على استخدام «عُمر العينة» لأنه محسوب من الصب، وعلى بلوغ ٢٨ يومًا مع عبارة أنه أحد أعمار اختبار المقاومة الشائعة.

نص مشهد المعالجة المعتمد: «معالجة العينات وفق متطلبات المواصفات القياسية».

نص الخاتمة المعتمد: «أجهزة مُعايرة… واختبارات وفق المواصفات القياسية».

العدّاد فوق الحوض، ويظهر بعد إنزال العينات، ويتقدم حتى ٢٨ يومًا ثم يثبت قبل الضغط. لا أرقام نتائج أو مواصفات أو شهادات اعتماد إضافية. تبقى النسخة السابقة وفكرة السلسلة كما هما.
