# إتقان البناء — النسخة السابعة مع توقيع المصمّم

إعادة شعار MS الأصلي إلى أقصى يسار الفوتر قبل البريد الإلكتروني، باللون الأبيض وخلفية شفافة، بعرض 46 بكسل ونسبه الأصلية. الشعار ثابت في جميع المشاهد، وارتفاع الفوتر 114 بكسل كما هو. أُعيد توزيع الهوامش الأفقية لاستيعاب التوقيع مع بقاء أحجام نصوص التواصل.

الفيديو رأسي 1080×1920، مدته 60 ثانية، 30 إطارًا/ثانية. الصوت هو نفس المزيج المعتمد في النسخة السادسة: تسجيل المستخدم موزع على المشاهد، مع الموسيقى والمؤثرات المخفضة تحت الكلام. بقية المشاهد والنصوص والتوقيتات والأرقام كما هي.

- public/music.m4a: الموسيقى والمؤثرات الأصلية.
- narration/recording-alignment.json: توقيتات فقرات التسجيل، وscript.txt هو النص.

## التعديل وإعادة البناء

Node.js، Chromium في /usr/bin/chromium، FFmpeg/FFprobe وPython مطلوبة.

```sh
npm ci
python3 -m pip install -r requirements.txt
npm run studio
npm run check
npm run render
python3 scripts/verify.py
python3 scripts/check_voice.py
python3 scripts/check_creator.py
python3 scripts/export_review.py
node scripts/check-playback.mjs
python3 scripts/package_source.py
```

إعادة إنتاج الفيديو تستخدم المزيج النهائي المرفق ولا تحتاج MP3 الأصلي. لإعادة المزج اختياريًا من التسجيل الأصلي، scripts/mix_voice.py --voice PATH يجهز المزيج فقط، ثم يلزم npm run render لتصدير التصميم الحالي. اختبار عدم تغير الصوت من النسخة السادسة مناسب لهذا التسليم؛ يتطلب تحديثه عند تغيير التسجيل عمدًا. لا يُنشر ملف MP3 الأصلي أو التخزين المؤقت.

## المراجعة والحدود

يتحقق scripts/check_creator.py من ظهور التوقيع في جميع إطارات الملف المصدّر. مقارنة مسار الصوت تثبت بقاء التعليق والموسيقى كما اعتُمدا. الفحص الصوتي تقني وليس اعتمادًا جديدًا للنطق في جلسة استماع بشرية. الرسوم SVG هندسية توضيحية، وليست تصويرًا واقعيًا أو إجراء اختبار كاملًا. عُمر 28 يومًا مثال توضيحي وليس قاعدة لكل الاختبارات.
