# إتقان البناء — النسخة الثامنة بتصميم التواصل المعتمد

فيديو رأسي 1080×1920، 60 ثانية، 30 إطارًا/ثانية. تطبيق التصور الذي اعتمده المستخدم في نهاية الفيديو، بثلاثة أسطر وسطية:

1. تواصل معنا، بالأبيض.
2. أيقونة التليفون على يسار 0551603205، في مجموعة واحدة بالذهبي.
3. لخدمات فحص الخرسانة، في سطر واحد بحجم أصغر.

الرقم مكتوب من اليسار إلى اليمين. المجموعة مفصولة عن الفوتر بنحو 80 بكسل. تُنفذ بالنصوص وSVG داخل مشهد متحرك؛ صورة التصور ليست أصلًا مستخدمًا في الفيديو.

بقية المشاهد والهيدر والفوتر وشعار المصمّم MS وأرقام التواصل والتعليق والموسيقى والتوقيتات هي نفسها النسخة السابعة. التعديل البصري في Closing.tsx فقط، مع تسجيل تركيب مستقل. جميع النسخ السابقة محفوظة.

## إعادة البناء

Node.js، Chromium في /usr/bin/chromium، FFmpeg/FFprobe وPython مطلوبة.

```sh
npm ci
python3 -m pip install -r requirements.txt
npm run studio
npm run check
npm run render
python3 scripts/verify.py
python3 scripts/check_voice.py
python3 scripts/check_creator.py
python3 scripts/export_review.py
node scripts/check-playback.mjs
python3 scripts/package_source.py
```

المزيج النهائي المرفق يكفي لإعادة التصدير؛ MP3 الأصلي غير منشور. لإعادة المزج من تسجيل جديد، scripts/mix_voice.py --voice PATH يجهز الصوت ثم يلزم npm run render. اختبار عدم تغيير الصوت عن النسخة السادسة يخص التسليم الحالي، ويُحدّث عند تغيير التسجيل عمدًا.

## حدود العرض والمراجعة

الرسوم SVG هندسية توضيحية، وليست تصويرًا واقعيًا أو إجراء اختبار كاملًا. عُمر 28 يومًا مثال وليس قاعدة لجميع العينات. فحص الصوت تقني عبر مطابقة المسار والمستويات والتوقيتات، وليس اعتمادًا جديدًا للنطق في جلسة استماع بشرية. تُحفظ فكرة السلسلة في notes/SERIES-CONCEPT.md دون إطلاق اسمها على الفيديو.
