# إتقان البناء — القوة لا تُفترض… بل تُختبر

إنتاج مستقل لاختبارات الخرسانة فقط، بنسبة 16:9، مدته 60 ثانية، ودقته 1920×1080 بمعدل 30 إطارًا/ثانية. جميع المشاهد مجسّمات إجرائية متحركة فعلًا في Three.js داخل Remotion؛ لا صور مشاهد ولا فيديو مخزون ولا أشخاص مولّدون.

## التسليم

- `renders/etqan-concrete-cinematic-60s-no-vo.mp4`: النسخة النهائية المتاحة بالموسيقى والمؤثرات فقط. وهي أيضًا النسخة المطلوبة دون تعليق صوتي؛ لا توجد نسختان مختلفتان صوتيًا في هذا التسليم.
- `renders/etqan-concrete-cover.png`: إطار كامل مأخوذ من الفيديو النهائي عند الثانية 55.8.
- `renders/etqan-concrete-source.zip`: المصدر القابل للتعديل، مع الشعار والخط والصوت الأصلي ونص الأداء.
- `narration/script.txt`: النص العربي المعتمد، دون إعادة صياغة.
- `narration/cues.json` و`voice-guide.srt`: توقيتات تسجيل مقترحة، وليست محاذاة لتسجيل صوتي موجود.
- `renders/verification.json` و`playback-check.json` و`scene-review.jpg`: أدلة الفحص.

لم تتوفر خدمة مناسبة لتوليد تعليق عربي احترافي. استُخدم البديل الذي أجازه الطلب: موسيقى ومؤثرات فقط، دون صوت آلي ضعيف أو استخدام التسجيل القديم ذي النص المختلف. لا يوجد ملف تعليق صوتي مولّد. يُعاد ضبط الخفض الموسيقي بعد تسجيل الصوت الفعلي.

## المسار البصري

| الزمن | التكوين والحركة |
|---|---|
| 0–7 ث | ماكرو لسطح خرسانة مقطوع، ثم حركة كاميرا إلى الصب داخل مخروط الهبوط |
| 7–17 ث | مخروط معدني مجوف، رفع رأسي منتظم لمدة خمس ثوانٍ، استقرار العينة ثم منظور علوي |
| 17–27 ث | ملء ثلاثة قوالب مكعبة بالتتابع، ثم تسوية السطح بعارضة متحركة |
| 27–37 ث | رف عينات مفكوكة القوالب ينخفض في الماء؛ مؤشر عمر ينتهي عند ٢٨ يومًا مع توضيح أنه أحد الأعمار الشائعة |
| 37–50 ث | جهاز ضغط بأربعة أعمدة، صفيحتا تحميل متلامستان مع العينة، تشقق محدود وشظايا صغيرة |
| 50–60 ث | انسحاب الكاميرا إلى مجموعة معدات متوازنة، والشعار الرسمي والاسم والعبارة الختامية |

الحركة مستمرة في فضاء ثلاثي الأبعاد واحد. لا توجد بطاقات مشاهد مرقمة، نتائج اختبار، أرقام مقاومة أو شهادات. لا توجد خدمات غير الخرسانة. لا هيدر أو فوتر من الأفلام السابقة؛ التوجيه الأحدث هو المرجع لهذا الإنتاج الجديد.

## المصدر والتعديل

- `src/Math.ts`: مسار الكاميرا وتوقيته.
- `src/Materials.ts`: الخامات الإجرائية والخرسانة والانعكاسات.
- `src/Slump.tsx`، `Preparation.tsx`، `Curing.tsx`، `Compression.tsx`: النماذج والحركة.
- `src/Fracture.ts`: إنشاء خلايا كسر ثلاثية الأبعاد هندسيًا، مع فصل خامة السطح الداخلي.
- `src/Stage.tsx`: الإضاءة وبيئة الانعكاس والظلال وعمق المجال.
- `src/Typography.tsx`: الخط العربي والعناوين والشعار.
- `scripts/make_audio.py`: تأليف وتوليف الموسيقى والمؤثرات الأصلية، دون عينات خارجية.
- `scripts/render.mjs`: تصدير قابل للاستئناف، يبطل الإطارات المخزنة عند تغير المصدر أو الأصول.

متطلبات التنفيذ: Node.js 22، Chromium، FFmpeg/FFprobe، Python 3 مع numpy وPillow. من هذا المجلد:

```sh
npm ci
python3 -m pip install -r requirements.txt
npm run check
npm run studio
python3 scripts/make_audio.py
npm run review
npm run render
python3 scripts/verify.py
python3 scripts/export_review.py
node scripts/check-playback.mjs
node scripts/check_camera.mjs
python3 scripts/check_brand.py
python3 scripts/check_geometry.py
python3 scripts/package_source.py
```

في Linux دون GPU تُستخدم `LIBGL_ALWAYS_SOFTWARE=1 EGL_PLATFORM=surfaceless`. السكربتات مضبوطة على Chromium في `/usr/bin/chromium`؛ يُعدّل المسار عند الحاجة. مجلدا `work` و`node_modules` محليان ومهملان في Git، ولا يلزم تسليمهما. لا يُنشر الاستوديو المحلي بوصفه رابط تسليم.

أُعيد تصدير إطارات مؤشر المعالجة بعد تصحيح موضعه وصياغة عدد الأيام. يوثق `renders/render-provenance.json` نطاق التعديل والمقاطع المعاد استخدامها خارج ظهور طبقة المؤشر؛ أما إعادة البناء من نسخة نظيفة فتصدّر الإطارات كلها من المصدر الحالي.

## الحدود الفنية

هذه رسوم PBR ثلاثية الأبعاد إجرائية محسّنة بالإضاءة والظلال وعمق المجال، وليست تصويرًا حقيقيًا أو إخراجًا فوتورياليستيًا كاملًا بمحاكاة ضوئية تتبعية. تدفق الخرسانة والهبوط وتحرك الماء والكسر حركات هندسية معدّة للإعلان؛ ليست محاكاة ريولوجية أو تحليل عناصر محددة معايرًا.

المخروط بنسب ارتفاع 300 وقطري 200/100 الشائعة، بحجم نسبي في المشهد. ارتفاع العينة يتغير مع الحفاظ على الحجم النظري لجذع المخروط، والرفع رأسي قبل إبعاد القالب. التفاصيل الصغيرة للسطح تضيف انحرافًا بصريًا طفيفًا. لا تُعرض قيمة هبوط أو مقاومة على أنها نتيجة فعلية.

إعداد العينات مختصر بصريًا؛ عمليات الدمك وفك القوالب والتصلب الأولي غير معروضة بالكامل، وتحدث بين اللقطات. يبدأ مشهد المعالجة بعينات متصلبة مفكوكة القوالب، ويظهر غمرها الكامل بعد إنزال الرف. لا يُعد الفيلم شرحًا لإجراء اختبار أو بديلًا للمواصفة الفنية. تجهيزات الصب والرفع نماذج إعلانية عامة، لا ادعاء بأنها صور تجهيزات المختبر الفعلية.

الشعار PNG الأصلي محفوظ حرفيًا دون تغيير نسبه أو ألوانه. يحتوي الأصل نفسه على الاسم والعبارة الإنجليزية المدمجة؛ احتُفظ بهما داخل الأصل التزامًا بعدم تغيير الشعار؛ ليستا نصًا إنجليزيًا أُضيف إلى الإعلان. جميع النصوص المؤلفة للفيلم عربية.

فحص الصوت يشمل ترابط مسار AAC مع التوليف الأصلي، والمدة والذروة وLUFS وفك الترميز. لا تتوفر في هذه البيئة مراجعة استماع بشرية أو اعتماد صوت رجالي عربي. المؤثرات مولّفة وليست تسجيلات ميدانية.

جميع الملفات الجديدة محصورة داخل هذا المشروع. لم يُستبدل أي فيلم أو مصدر سابق.
