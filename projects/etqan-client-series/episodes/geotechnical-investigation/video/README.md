# إتقان | من الفحص إلى القرار

## من استكشاف التربة… إلى قرار التأسيس

إنتاج مستقل رأسي مدته 60 ثانية، 1080×1920، 30 إطارًا/ثانية. مشاهد هندسية مرسومة ومظللة، تتحرك وفق إطار Remotion؛ لا صور فوتوغرافية ولا مشاهد جاهزة أو تكبير لصور مولّدة.

حفر واستكشاف طبقات التربة، سحب العينة وحفظها، مثال لاختبار التدرّج الحبيبي، تكامل بيانات الموقع مع نتائج المختبر، ثم غلاف تقرير الدراسة الجيوتقنية والتوصيات والهوية والتواصل.

| الفترة | المحتوى |
|---|---|
| 0–8 ث | عنوان الحلقة والحفارة |
| 8–24 ث | رأس الحفر وعمود أخذ العينة داخل قطاع الطبقات |
| 24–30 ث | حفظ العينة وإغلاق حاويتها |
| 30–42 ث | اختبار التدرّج الحبيبي مثالًا للاختبارات المعملية |
| 42–52 ث | التحليل والتقرير وتوصيات التأسيس |
| 52–60 ث | الهوية والتواصل |

الهيدر والفوتر وشعار MS الصغير مستمرة طوال الحلقة. يخرج نص المشهد قبل دخول نص المشهد التالي؛ لا تتراكب العناوين أثناء النقلات. يظل برج الحفارة كاملًا داخل إطار الرسم أثناء الاقتراب. الفوتر: 0535588975، info@etqanelbnaa.com، حي القادسية، الرياض. رقم التواصل الختامي: 0551603205، وأيقونة الهاتف على يساره.

## المخرجات

- `renders/etqan-series-geotechnical-60s.mp4`: النسخة النهائية بالموسيقى والمؤثرات الأصلية، دون تعليق صوتي.
- `renders/etqan-series-geotechnical-cover.png`: إطار كامل من الفيديو الفعلي.
- `renders/etqan-series-geotechnical-source.zip`: المصدر القابل للتعديل والأصول والخط وتراخيصه وأدلة الفحص.
- `narration/script.txt`: نص عربي جديد للتسجيل.
- `narration/cues.json`: نوافذ أداء مقترحة للجمل؛ ليست محاذاة لتسجيل موجود.
- `public/score.m4a`: المسار الموسيقي والمؤثرات منفصلًا، AAC stereo 48 kHz.

لم تُستخدم تسجيلات التعليق السابقة الخاصة بالخرسانة. لم تتوفر خدمة تعليق عربي احترافي مناسبة؛ لا يوجد تسجيل صوتي جديد يُنسب إلى النص المقترح.

## إعادة الإنتاج

Node 24، Python 3، Chromium، FFmpeg؛ إصدارات Remotion/React مثبتة في ملف القفل.

```sh
npm ci
python3 -m pip install -r requirements.txt
python3 scripts/make_audio.py
npm run check
npm run studio
```

في الاستوديو افتح `EtqanSeriesGeotechnical`. كل مشهد له تركيب مستقل أيضًا. بعد المراجعة:

```sh
mkdir -p /tmp/etqan-geo
TMPDIR=/tmp/etqan-geo npm run render
python3 scripts/verify.py
python3 scripts/export_review.py
python3 scripts/check_creator.py
TMPDIR=/tmp/etqan-geo node scripts/check-playback.mjs
node scripts/check-geometry.mjs
python3 scripts/package_source.py
```

سكربتات المتصفح تستخدم `/usr/bin/chromium`؛ عدّل المسار عند اختلاف نظام التشغيل. مجلد `work/` مؤقت وغير مشمول بالمصدر المضغوط. التصدير يستأنف أجزاء الفيديو المكتملة إذا تطابقت بصمة المصدر. يجب حذف/إعادة تسمية الأجزاء عند تغيير برنامج التصدير نفسه دون تغيير المصدر.

## حدود العرض

رسوم هندسية متحركة بتظليل يمنح العمق؛ ليست تصويرًا ميدانيًا، وليست محاكاة فيزيائية أو نموذج CAD معتمدًا للحفارة. الحفارة ذات البرج الواحد مستلهمة من الصور التي أرسلها المستخدم؛ لا تدّعي دقة كل تفاصيل تصنيع المعدة. قطاع الطبقات وأخذ العينة يختصران العملية ولا يحددان عمقًا أو طريقة اختبار حقلي خاصة.

المناخل مثال على جزء من برنامج اختبارات يحدده المشروع. لا يستنتج الفيلم قدرة التحمل من التصنيف وحده. التقرير غلاف توضيحي بلا نتائج أو عميل أو توقيع أو اعتماد مختلق. المصادر العلمية وحدود الاطلاع في `notes/research-and-brief.md`.

جميع المشروعات السابقة محفوظة؛ هذا العمل لا يستبدل حلقة الخرسانة أو فيديوهاتها.
