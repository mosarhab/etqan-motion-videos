# Provenance and production notes

- **Only static image asset:** the authentic, unchanged ETQAN logo PNG from repository root at commit `567187d949ff260176b68531fd21057eacf0686e`. Its Git blob SHA is `731714d1fbf04b75278aa277dc697f498af9881d`. It is copied into this project's `public/assets/etqan-logo.png`; the root source is not modified. The palette uses its dominant opaque navy `#1D305B` and yellow `#F6C717`.
- **All scene imagery:** original procedural Three.js geometry, perspective cameras, physically based materials, generated studio reflection environment, shadows, particles, depth-of-field and filmic post-processing. There are no photographs, stock images, AI-generated scene images, still-image slide scenes, stock laboratory clips or downloaded HDR environments. Grain maps are deterministic arrays generated inside the shader pipeline, not image files. Equipment is virtual and is not presented as documentary imagery of the actual laboratory.
- **Geography:** Natural Earth 1:110m Admin 0 countries, public domain. Original data: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson . Terms: https://www.naturalearthdata.com/about/terms-of-use/ . Country contours are tessellated into spherical 3D land meshes and an extruded Saudi outline. No Google map screenshots, tiles or trademarks appear.
- **Location accuracy:** The user supplied the exact point 24.829475 N, 46.828527 E earlier in this thread, for the same Google Maps short reference. The 3D beacon is anchored to that supplied point. The short link could not be independently opened by the available browsing tool. Company city-level context is supported by its official contact page at https://etqanelbnaa.com/en/contact-us-2/ . The abstract architectural massing is original and is not a surveyed road or building model. No exact street address or coordinates are displayed in the film. The supplied precise point is not claimed to have been independently verified against the live Maps listing.
- **Typeface:** Cairo, SIL Open Font License 1.1, local Arabic/Latin subsets from `@fontsource/cairo` 5.3.0; license included at `public/assets/Cairo-OFL.txt`.
- **Music and effects:** original deterministic synthesis and sound design, authored by `scripts/create-score.py`. No external music, samples or sound-effect recordings are used. The compressed AAC file is a production asset; the intermediate WAV is retained under `work/audio/`.
- **Visual limitations:** deliberately stylized cinematic real-time 3D, not path-traced photorealistic footage. To run on the available software GPU, the 3D pass renders at 720×1280 with multisampling and is composited into 1080×1920 output. Arabic typography and the authentic logo are composited at the full output resolution. There is no frame interpolation: all 1800 authored frame states are rendered.
