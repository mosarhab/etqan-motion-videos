# إتقان البناء — تعديل رأسي لآخر فيديو

نسخة مستقلة مبنية على `etqan-concrete-client-explainer-60s`، بدقة 1080×1920 ونسبة 9:16، ومدتها 60 ثانية بمعدل 30 إطارًا/ثانية. بقي الفيديو الأفقي الأصلي وجميع المشروعات السابقة دون تغيير.

## التعديلات المطلوبة

- إعادة توزيع الهيدر والعنوان والرسم والفائدة والفوتر على كادر رأسي كامل؛ لا قص أو تدوير للفيديو الأفقي.
- استبدال «اعرف ما الذي نفحصه، ولماذا يهمّ مشروعك» بـ«اختبارات تعطيك صورة أوضح عن جودة الخرسانة».
- جمع شرح إعداد العينات في «تجهيز دقيق للعينات… لتقييم سليم لمقاومة الخرسانة»، وحذف العبارة المكررة أسفل الرسم ووصف الخرسانة المورّدة المكرر.
- انتقالات مدتها 18 إطارًا مع حركة رأسية لطيفة، مع إظهار القالب المرفوع وخروجه تدريجيًا، وتنعيم بدء وإيقاف حركة قضيب الدمك، وتموّج متدرج أثناء الغمر، وظهور متتابع للشروخ أثناء تطبيق الحمل.
- الاحتفاظ بالافتتاحية «القوة لا تُفترض… بل تُختبر»، وبفحوصات الهبوط والحرارة معًا، وبعينات المقاومة الأسطوانية، وبالمعالجة قبل الضغط.
- الهيدر والفوتر ثابتان طوال الفيلم. البيانات المعتمدة: `0535588975`، `info@etqanelbnaa.com`، «حي القادسية، الرياض». لا توجد أرقام إضافية.

## فكرة السلسلة المحفوظة

حُفظت مناقشة فكرة السلسلة في [notes/SERIES-CONCEPT.md](notes/SERIES-CONCEPT.md). الاسم المرشّح «إتقان | من الفحص إلى القرار»، مع بدء محدود بموضوع الخرسانة، ثم التوسع لاحقًا إلى التربة والمواد. الفكرة مذكرة للتطوير لاحقًا؛ لم تُضف تسمية السلسلة أو حلقاتها المستقبلية إلى الفيديو الحالي.

## المشاهد

| الزمن | المحتوى |
|---|---|
| 0–6 ث | الافتتاحية والعبارة المعدّلة عن جودة الخرسانة |
| 6–20 ث | الهبوط ودرجة الحرارة قبل الصب |
| 20–32 ث | إعداد العينات الأسطوانية مع النص المختصر الجديد |
| 32–43 ث | معالجة العينات بعد التصلب وفك القوالب |
| 43–55 ث | تطبيق الحمل على الأسطوانة وظهور الشروخ |
| 55–60 ث | اسم المختبر والدعوة للتواصل |

يحدث تداخل بصري 0.6 ثانية بين المشاهد. الرسوم SVG هندسية متحركة بالفعل مع خامات إجرائية؛ لا صور مشاهد أو فيديو مخزون أو مجسّمات WebGL/Three.js. الشعار الرسمي وحده ملف صورة مستخدم في الفيلم، مع المعالجة البيضاء والذهبية التي سبق أن طلبها المستخدم، ودون تغيير نسب التصميم أو أصل PNG.

## التسليم

- `renders/etqan-concrete-client-portrait-v2-60s.mp4`: الفيلم الرأسي الكامل بالموسيقى والمؤثرات، دون تعليق صوتي.
- `renders/etqan-concrete-portrait-v2-cover.png`: غلاف كامل مستخرج من الفيديو.
- `renders/etqan-concrete-portrait-v2-source.zip`: المصدر والخط والشعار والصوت والنص وتوقيتاته ومذكرة فكرة السلسلة وتقارير الفحص الصغيرة.
- `narration/script.txt` و`cues.json`: دليل تسجيل التعليق المقترح، وليس تسجيلًا مولّدًا أو محاذاة فعلية لصوت.
- `renders/verification.json` و`playback-check.json` و`review-frames.json`: أدلة الفحص.

لم يتوفر توليد صوت عربي احترافي. احتُفظ بموسيقى ومؤثرات النسخة السابقة الأصلية، مع تحديث نص التسجيل ليتفق مع تعديل وصف العينات. لا يُستخدم تسجيل المستخدم القديم ذو الخدمات المختلفة.

## المصدر والبناء

كل مشهد محفوظ في ملف مستقل ومسجل في Remotion Studio. `Scene.tsx` يحتوي التوزيع الرأسي والانتقالات؛ `Brand.tsx` للهيدر والفوتر، و`Drawing.tsx` للعينات والخامات والشروخ. الحركة كلها مشتقة من رقم الإطار ولا تستخدم مؤقتات أو CSS animation تعتمد على وقت التشغيل.

متطلبات البناء: Node.js، وChromium، وFFmpeg/FFprobe، وPython. مسار Chromium في السكربتات `/usr/bin/chromium` ويُعدّل عند الحاجة.

```sh
npm ci
python3 -m pip install -r requirements.txt
npm run studio
npm run check
npm run review
npm run render
python3 scripts/verify.py
python3 scripts/export_review.py
node scripts/check-playback.mjs
python3 scripts/package_source.py
```

شغّل Studio في نافذة مستقلة. الصوت الجاهز موجود في `public/score.m4a`؛ إعادة التوليف بواسطة `make_audio.py` اختيارية. رابط Studio محلي للمعاينة، وليس رابط تسليم. لا تُشحن مجلدات التبعيات أو التخزين المؤقت.

## الحدود

الرسوم تبسيط دعائي للعميل وليست تصويرًا حقيقيًا أو محاكاة معايرة أو شرح مواصفة اختبار كاملًا. تُختصر مراحل الملء والدمك والانتظار وتجهيز أسطح التحميل. وعاء الحرارة مقطع توضيحي في خرسانة غير متصلبة، وليس مكعب اختبار مقاومة. لا تظهر قراءات حرارة أو هبوط أو مقاومة مختلقة، ولا يُستدل بالهبوط والحرارة وحدهما على صلاحية الخرسانة كاملة.

الموسيقى والمؤثرات أصلية مولّفة برمجيًا وليست تسجيلات ميدانية. مراجعة الصوت تقنية عبر فك الترميز والمستويات والترابط مع الأصل؛ ليست جلسة استماع بشرية أو اعتماد استوديو صوت. العبارة الإنجليزية المدمجة في الشعار جزء من الأصل، وكل النصوص المؤلفة للفيلم عربية، باستثناء بيانات التواصل التي اعتمدها المستخدم.
