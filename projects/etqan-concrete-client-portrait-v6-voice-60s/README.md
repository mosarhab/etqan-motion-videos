# إتقان البناء — النسخة الرأسية السادسة بالتعليق الصوتي

فيديو رأسي كامل 1080×1920، مدته 60 ثانية، بمعدل 30 إطارًا/ثانية. دمج تسجيل ElevenLabs الأخير الذي أرسله المستخدم مع النسخة الخامسة. تبقى جميع النسخ السابقة محفوظة.

## الصوت والتزامن

- التسجيل الأصلي نحو 48.27 ثانية؛ لم تتغير سرعته أو طبقته.
- فُصلت الفقرات داخل الوقفات الطبيعية، ووُزعت على الافتتاحية، الهبوط والحرارة، إعداد العينات، المعالجة، الضغط، والخاتمة.
- خُفضت الموسيقى تحت التعليق، مع دخول وخروج تدريجي بين الفقرات.
- نهاية التعليق قرب الثانية 59.52، داخل الستين ثانية. التوقيتات الدقيقة في narration/recording-alignment.json.
- النص المرسل للتسجيل في narration/script.txt؛ دليل SRT للتوقيت وليس عناوين داخل الفيديو.

الصورة والحركة والهيدر والفوتر وأيقونة التليفون وأرقام التواصل هي نفسها النسخة الخامسة. نُسخ مسار الفيديو كما هو دون إعادة ضغط، مع مزيج صوتي جديد. عبارة «بأحدث الأجهزة» واردة في التسجيل؛ النص المرئي السابق عن الأجهزة المُعايرة باقٍ كما هو.

## التسليم

- renders/etqan-concrete-client-portrait-v6-voice-60s.mp4: النسخة بالتعليق والموسيقى والمؤثرات.
- renders/etqan-concrete-portrait-v6-voice-cover.png: لقطة الختام من الملف النهائي.
- renders/etqan-concrete-portrait-v6-voice-source.zip: المصدر والأصول الصوتية الجاهزة والخط والشعار والتوقيتات وتقارير الفحص.
- public/score.m4a: المزيج النهائي المستخدم في الفيديو.
- public/music.m4a: الموسيقى والمؤثرات الأصلية قبل إضافة التسجيل.

الـMP3 الأصلي غير منشور. يوجد المزيج النهائي ضمن أصول المشروع لإعادة إنتاج الفيديو.

## التعديل وإعادة البناء

Node.js وChromium وFFmpeg/FFprobe وPython مع متطلبات requirements.txt مطلوبة.

```sh
npm ci
python3 -m pip install -r requirements.txt
npm run studio
npm run check
npm run render
python3 scripts/verify.py
python3 scripts/export_review.py
node scripts/check-playback.mjs
python3 scripts/package_source.py
```

إعادة المزج من التسجيل الأصلي اختيارية عبر scripts/mix_voice.py --voice PATH، وتحتاج مشروع النسخة الخامسة المجاور لتنسخ مسار الفيديو الأصلي. إعادة التصدير الكاملة من المصدر تستخدم المزيج المرفق ولا تحتاج MP3 الأصلي.

## حدود المراجعة

الرسوم الهندسية SVG توضيحية؛ ليست تصويرًا واقعيًا أو إجراء اختبار كاملًا. عُمر 28 يومًا مثال توضيحي، وليس عمرًا إلزاميًا لجميع الاختبارات.

مراجعة الصوت تمت عبر التعرف الآلي المحلي لتحديد الفقرات، وفواصل الصمت، والمستويات، وفك الترميز والمقارنة الموجية. لا يُدّعى اعتماد النطق في جلسة استماع بشرية. مصدر الموسيقى أصلي، والتعليق تسجيل مقدّم من المستخدم.
