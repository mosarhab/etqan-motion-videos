# إتقان البناء — شرح فحوصات الخرسانة للعملاء

إنتاج جديد مستقل، أفقي 1920×1080، مدته 60 ثانية بمعدل 30 إطارًا/ثانية. يبدأ بعبارة «القوة لا تُفترض… بل تُختبر»، ويعرض ما يتم في الاختبارات وفائدته للعميل.

الأسلوب رسوم هندسية توضيحية متحركة باستخدام SVG وReact: لا مشاهد مختبر ثلاثية الأبعاد، ولا Three.js أو WebGL، ولا صور مشاهد ثابتة، أو تصوير مخزون، أو لقطات من الفيديوهات السابقة. التدرجات والخامات النقطية مرسومة برمجيًا. الشعار الرسمي هو ملف الصورة الوحيد المستخدم في الفيلم.

## ترتيب المشاهد

| الزمن | المحتوى | الفائدة المعروضة |
|---|---|---|
| 0–6 ث | القوة لا تُفترض… بل تُختبر | تقديم رحلة التحقق من جودة الخرسانة |
| 6–20 ث | اختبار الهبوط وقياس درجة الحرارة معًا | المساعدة في تقييم القوام والملاءمة قبل الصب |
| 20–32 ث | إعداد عينات أسطوانية: ملء القوالب وتجهيزها | عينات تمثّل الخرسانة لتقييم المقاومة لاحقًا |
| 32–43 ث | معالجة العينات بعد التصلب وفك القوالب | أساس لتقييم المقاومة وفق المتطلبات وعمر الاختبار |
| 43–55 ث | تطبيق الحمل على عينة أسطوانية حتى التشقق | نتائج تدعم تقييم المطابقة والقرار الهندسي |
| 55–60 ث | هوية المختبر ودعوة للتواصل | نتائج تدعم القرار الهندسي؛ الدقة أساس الثقة |

عينات المقاومة أسطوانية في التجهيز والمعالجة والضغط. لم تستخدم مكعبات خرسانية. وعاء قياس الحرارة مقطع توضيحي في خرسانة غير متصلبة. الهبوط له شكل مخروط الاختبار المعتاد. المعالجة تسبق تطبيق حمل الضغط. الانتقالات تتداخل 12 إطارًا، مع تحريك الرسم نفسه داخل كل مرحلة. لا ترقيم مشاهد ولا نتائج اختبار مختلقة أو درجات حرارة رقمية.

## الهوية الثابتة

الهيدر: الشعار الأصلي مع المعالجة البيضاء والذهبية التي طلبها المستخدم سابقًا، واسم مختبر إتقان البناء لفحص التربة والمواد. لم يُعد رسم الشعار أو تغيير نسبه، وملف PNG مطابق لأصل المستودع. العبارة الإنجليزية المدمجة داخل الأصل جزء من الشعار؛ كل النصوص المؤلفة للفيديو عربية.

الفوتر: شريط رفيع في آخر 90 بكسل أسفل الإطار، مع الرقم المعتمد فقط `0535588975`، والبريد `info@etqanelbnaa.com`، والعنوان «حي القادسية، الرياض». لم تُعد الأرقام الأخرى أو شعار صانع الفيديو إلى هذا الإنتاج.

## الملفات

- `renders/etqan-concrete-client-explainer-60s.mp4`: الفيديو كاملًا، موسيقى ومؤثرات دون تعليق صوتي.
- `renders/etqan-concrete-explainer-cover.png`: غلاف كامل مأخوذ من إطار الفيديو النهائي.
- `renders/etqan-concrete-explainer-source.zip`: المصدر والأصول المرخصة ونص التسجيل وتقارير الفحص الصغيرة.
- `narration/script.txt`: نص عربي جاهز للتسجيل.
- `narration/cues.json` و`recording-guide.srt`: توقيتات أداء مقترحة؛ ليست محاذاة لتسجيل موجود.
- `renders/verification.json` و`playback-check.json` و`review-frames.json`: فحوص الملف والتشغيل والإطارات.

لم تتوفر خدمة لتوليد تعليق عربي احترافي. استُخدم بديل الموسيقى والمؤثرات المسموح به سابقًا، مع شرح الفائدة على الشاشة ودليل تسجيل منفصل. لا يوجد ملف صوت رجالي مولّد، ولم يُستخدم التسجيل القديم ذو الخدمات المختلفة.

## المصدر والتعديل

`src/Root.tsx` يحتوي التوقيتات الرئيسية وتركيب المشاهد. كل مشهد في ملف مستقل ومسجل منفردًا في Studio. `Brand.tsx` للهيدر والفوتر والخط والشعار، و`Scene.tsx` لتوزيع الشرح والفائدة، و`Drawing.tsx` للخامات والعينات والأسطح. حركة كل العناصر مشتقة من رقم الإطار، دون مؤقتات أو رسوم تعتمد على ساعة المتصفح.

يتطلب البناء Node.js، وChromium في `/usr/bin/chromium`، وFFmpeg/FFprobe، وPython. في مجلد المشروع:

```sh
npm ci
python3 -m pip install -r requirements.txt
npm run studio
npm run check
python3 scripts/make_audio.py
npm run review
npm run render
python3 scripts/verify.py
python3 scripts/export_review.py
node scripts/check-playback.mjs
python3 scripts/package_source.py
```

لـStudio شغّل الأمر في نافذة منفصلة، ثم استخدم أوامر التصدير من نافذة أخرى. رابط Studio المحلي للمعاينة وليس بديلًا عن ملف التسليم. مجلدا `node_modules` و`work` غير مشمولين بالتسليم. المصدر يتضمن `score.m4a` الجاهز؛ يمكن إعادة توليفه بالسكربت، وليس شرطًا تشغيل التوليف مجددًا قبل البناء.

## حدود العرض

هذه رسوم توضيحية تعليمية دعائية؛ ليست تصويرًا فعليًا لاختبارات المختبر أو نموذجًا هندسيًا معايرًا. يختصر الرسم عدد مراحل الملء والدمك والتسوية وأوقات الانتظار، ولا يقدّم تعليمات تنفيذ أو ادعاء بمطابقة جهاز معين. المرور من التجهيز إلى المعالجة يلخّص التصلب الأولي وفك القوالب؛ النص يذكر ذلك صراحة.

الهبوط وتغيّر سطح الماء وتشققات العينة حركات معدّة للتوضيح، دون نتائج رقمية. لا تُستنتج صلاحية الخرسانة الكاملة من الهبوط والحرارة وحدهما؛ صياغة الإعلان «للمساعدة في التقييم» مقصودة. مقاومة الضغط تدعم تقييم المهندس للمقاومة المطلوبة ولا تضمن نتيجة قبول.

الصوت مؤلَّف ومولَّف برمجيًا، وليست المؤثرات تسجيلات ميدانية. مراجعة الصوت تقنية عبر فك الترميز والمستوى والترابط مع المسار الأصلي؛ لا يوجد اعتماد استوديو صوت أو جلسة استماع بشرية في هذه البيئة.

كل ملفات هذا العمل محصورة داخل مجلد المشروع الجديد. جميع المشروعات السابقة محفوظة.
