# إتقان | من الفحص إلى القرار — افتتاحية أرض الموقع

إصدار V4 مستقل، مدته100 ثانية، رأسي1080×1920 بمعدل30 إطارًا/ثانية، H.264/AAC. تطوير لافتتاحية النسخة السابقة فقط، مع الحفاظ على رسم الحفارة والهيدر والفوتر والخط والشعارين وجميع المشاهد التالية.

تبدأ اللقطة بأرض خالية، وتُرسم حدود الموقع دون أرقام، ثم تتحول زاوية العرض وينكشف قطاع الطبقات. تظهر الحفارة تدريجيًا عند3.5–4.5 ثانية، ويبدأ الحفر مع العنوان الكامل. عبارة البداية «قبل التأسيس…». التمهيد داخل زمن المشهد الأول، لا يطيل الفيلم ولا يغيّر مواضع المشاهد التالية.

| الوقت | المحتوى |
|---|---|
| 0–4.5 | أرض خالية، حدود الموقع، كشف متصل للطبقات ثم ظهور الحفارة |
| 4.5–12 | الحفر والجسات واستكشاف الطبقات |
| 12–22 | مجموعات الصخور: رسوبية، نارية، متحولة؛ أمثلة عامة |
| 22–43 | الاختراق القياسي SPT ثم استرجاع العينة وحفظها |
| 43–51 | المحتوى المائي: وزن وتجفيف وإعادة وزن |
| 51–60 | التدرّج الحبيبي وتصنيف التربة |
| 60–69 | حدود أتربرج؛ حد السيولة مثالًا |
| 69–78 | القص المباشر |
| 78–86 | رصد المياه الجوفية عند الحاجة |
| 86–94 | التحليل والتقرير وتوصيات التأسيس |
| 94–100 | الهوية والتواصل |

## الملفات

- `renders/etqan-series-geotechnical-v4-100s.mp4`: الفيلم الكامل بالموسيقى والمؤثرات فقط.
- `renders/etqan-series-geotechnical-v4-cover.png`: غلاف من الإطار135، ثانية4.5، من MP4 الفعلي.
- `renders/etqan-series-geotechnical-v4-source.zip`: المصدر والأصول والخط والتراخيص وأدلة الفحص.
- `public/score.m4a`: الموسيقى والمؤثرات الأصلية منفصلة؛ يبدأ صوت الحفر بعد تمهيد الأرض.
- `narration/script.txt`: أحدث نص أداء ناقشه المستخدم. أفاد أن تسجيله90 ثانية، لكن ملف التسجيل الجديد لم يُرفع، لذلك لم تتم محاذاته أو دمجه. `cues.json` يوضح هذا الوضع ونوافذ المشاهد دون ادعاء توقيت الكلام الفعلي.

هذا التعديل للافتتاحية فقط؛ لا يدّعي إضافة مشاهد مقاومة عينات الصخور أو الكيمياء الواردة في نص الأداء الأحدث. يجب مراجعة توافق بقية النص والصورة عند وصول التسجيل، قبل اعتماد نسخة بتعليق صوتي.

## إعادة الإنتاج

Node24، Python3، FFmpeg، Chromium. إصدارات JavaScript مثبتة في ملف القفل. المتصفح `/usr/bin/chromium` قابل للتعديل بحسب البيئة.

```sh
npm ci
python3 -m pip install -r requirements.txt
python3 scripts/make_audio.py
npm run check
npm run studio
```

تركيب Studio الرئيسي `EtqanSeriesGeotechnicalV4`، المنفذ3030. المشاهد مسجلة كعناصر JSX مستقلة قابلة للتحرير.

```sh
mkdir -p /tmp/etqan-v4
TMPDIR=/tmp/etqan-v4 npm run render
node scripts/check-geometry.mjs
python3 scripts/verify.py
python3 scripts/export_review.py
python3 scripts/check_creator.py
TMPDIR=/tmp/etqan-v4 node scripts/check-playback.mjs
python3 scripts/package_source.py
```

التصدير يستأنف الأجزاء المطابقة لبصمة المصدر. استُخدمت في هذه النسخة أجزاء الفيديو الصامتة التي لم تتغير من التصدير السابق، بعد مطابقة مصدرها وأصولها ومددها؛ أُعيد رسم أول600 إطار وترميز الفيلم كاملًا مع المسار الصوتي المحدّث. التفاصيل والبصمات في `renders/checkpoint-reuse.json`. ملف المصدر المستقل يعيد رسم جميع الإطارات عند غياب ذاكرة التصدير السابقة؛ سكربت إعادة الاستخدام اختياري.

## حدود التمثيل

رسوم هندسية SVG مظللة ومتحركة فعلًا وفق الإطارات؛ ليست تصويرًا ميدانيًا أو نماذج ثلاثية الأبعاد فوتوريالية أو محاكاة اختبار معتمدة. الأبعاد والأزمنة مختصرة بصريًا، وحدود الموقع توضيحية. لا نتائج أو أعماق أو قراءات أو قيمةN مختلقة.

SPT في طبقات التربة عند قاع جسة سبق حفرها، وليس اختبارًا للصخور أو تحديدًا منفردًا مباشرًا لقدرة التحمل. العينات المسترجعة بالطرق مضطربة؛ يُختار نوع العينة والفحوص وفق الدراسة. الصخور أمثلة عامة لا تصف موقعًا معينًا. المحتوى المائي مختصر زمنيًا؛ لا قراءات مزعومة. كأس السيولة مثال ضمن حدود أتربرج، والقص مقطع يوضح المبدأ. المياه الجوفية رصد عند الحاجة بلا منسوب مقاس. التقرير غلاف توضيحي بلا عميل أو نتائج أو توقيع مختلق.

التقرير الخاص الذي أرسله المستخدم غير مضمن في المشروع أو الأرشيف العام. جميع الإصدارات السابقة محفوظة.
