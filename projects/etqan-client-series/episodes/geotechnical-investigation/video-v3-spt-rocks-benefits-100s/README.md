# إتقان | من الفحص إلى القرار — الجسات والصخور والاختبارات

نسخة موسعة مستقلة،100 ثانية، رأسية1080×1920 و30fps، H.264/AAC. نفس رسم الحفارة والهيدر والفوتر والألوان والخط والشعارين من النسخة السابقة، مع فوائد واضحة لكل مرحلة. لا مبانٍ قائمة في موقع الجسات، ولا تصوير من مختبرات أو مواقع أخرى.

أكّد المستخدم تنفيذSPT وطلب إبرازه، ثم طلب أنواع الصخور أيضًا. جُهزت فقرة الصخور داخل هذه النسخة، مستقلة زمنيًا وقابلة للفصل، وامتدت المدة من المقترح90 إلى100 ثانية لمنح المحتوى مساحة.

| الوقت | المحتوى |
|---|---|
| 0–12 | حفر نشط واستكشاف الطبقات على أرض خالية |
| 12–22 | رسوبية/حجر جيري، نارية/جرانيت، متحولة/رخام، وتوصيف الصخر |
| 22–43 | SPT في طبقات التربة، سحب العينة ثم حفظها |
| 43–51 | المحتوى المائي الطبيعي: وزن وتجفيف وإعادة وزن |
| 51–60 | التدرّج الحبيبي وتصنيف التربة |
| 60–69 | حدود أتربرج: حد السيولة مثالًا |
| 69–78 | القص المباشر |
| 78–86 | رصد المياه الجوفية بالبيزومتر عند الحاجة |
| 86–94 | تكامل المعلومات والتحليل والتقرير والتوصيات |
| 94–100 | الهوية والتواصل |

## المخرجات

- `renders/etqan-series-geotechnical-v3-100s.mp4`: الفيلم الكامل بالموسيقى والمؤثرات فقط.
- `renders/etqan-series-geotechnical-v3-cover.png`: غلاف من الإطار30 في الفيديو الفعلي.
- `renders/etqan-series-geotechnical-v3-source.zip`: المصدر والأصول والخط وتراخيصه وأدلة الفحص.
- `narration/script.txt` و`cues.json`: نص أداء جديد ونوافذ تسجيل مقترحة؛ لا تعليق بشري مولد أو مدمج، وفق طلب المستخدم أن يضيفه لاحقًا.
- `public/score.m4a`: مسار الموسيقى والمؤثرات الأصلية منفصلًا.

## التحرير وإعادة الإنتاج

Node24، Python3، FFmpeg، Chromium. إصدارات JavaScript مثبتة بملف القفل. مسار المتصفح في السكربتات `/usr/bin/chromium`، ويمكن تعديله بحسب النظام.

```sh
npm ci
python3 -m pip install -r requirements.txt
python3 scripts/make_audio.py
npm run check
npm run studio
```

افتح `EtqanSeriesGeotechnicalV3`. لكل مشهد تركيب مستقل داخل Studio، بما فيه `Rocks` و`SPT`. تسجيلات المشاهد والتوقيتات مؤلفة كعناصر JSX مستقلة قابلة للتحرير.

```sh
mkdir -p /tmp/etqan-v3
TMPDIR=/tmp/etqan-v3 npm run render
node scripts/check-geometry.mjs
python3 scripts/verify.py
python3 scripts/export_review.py
python3 scripts/check_creator.py
TMPDIR=/tmp/etqan-v3 node scripts/check-playback.mjs
python3 scripts/package_source.py
```

يستأنف التصدير الأجزاء المتطابقة مع بصمة المصدر. لا يشمل الأرشيف `node_modules/` أو `work/` أو تسجيلات المستخدم السابقة أو ملف Excel.

## الدقة وحدود التمثيل

رسوم هندسية مظللة ومتحركة وفق الإطارات، ليست فيديو ميدانيًا أو نماذجCAD أو محاكاة فيزيائية/اختبارية معتمدة. الأبعاد والأزمنة مختصرة بصريًا. لا قيمN أو أعماق أو قراءات أو نتائج أو شهادات مختلقة.

SPT يظهر في طبقات التربة عند قاع جسة سبق حفرها، مع مطرقة/سندان وعمود وأداة أخذ عينة؛ ليس اختبارًا على الصخور ولا تحديدًا مباشرًا منفردًا لقدرة التحمل. العينات المسترجعة بالطرق مضطربة، وتُختار العينات والفحوص وفق متطلبات الدراسة؛ لا يدّعي الرسم أنها صالحة تلقائيًا لكل فحص معمل.

أنواع الصخور أمثلة عامة، لا وصفًا لصخور موقع فعلي أو دليلًا كافيًا وحده على المقاومة؛ تؤخذ التجوية والفواصل ضمن التوصيف الهندسي. مشهد المحتوى المائي يختصر التجفيف زمنيًا ولا يعرض قراءات أو درجة حرارة أو زمنًا محددًا. كأس السيولة مثال ضمن حدود أتربرج، وصندوق القص مقطع يوضح المبدأ، ومشهد المياه الجوفية رصد عند الحاجة بلا منسوب مقاس معروض.

التقرير غلاف توضيحي بلا نتائج أو عميل أو مشروع أو توقيع مختلق. المراجع في `notes/`. جميع الإصدارات السابقة محفوظة.
